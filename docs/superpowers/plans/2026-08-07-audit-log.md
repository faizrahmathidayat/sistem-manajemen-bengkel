# Audit Log (Migration 011) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fail-safe `AuditLogger` service backed by a new `audit_logs` table, wired into the 10 critical business events named in the design doc (Invoice post/cancel, Payment Receipt create/void, Stock Adjustment post, Stock Transfer dispatch/receive/void, branch permission grant/revoke), plus a filterable read-only viewer activating the disabled "Audit Log" sidebar placeholder.

**Architecture:** New schema (`audit_logs`) + model (`AuditLog`) + constants (`AuditEvent`) + service (`AuditLogger`, fail-safe by construction) in Task 1. Tasks 2-4 are cross-cutting retrofits — each adds one `(new AuditLogger())->log(...)` call inside an already-shipped, already-tested Service/Controller method's existing `DB::transaction()` closure, changing no existing business logic. Task 5 is the new read-only `AuditLogController` + UI. Design doc: `docs/superpowers/specs/2026-08-07-audit-log-design.md`.

**Tech Stack:** Laravel 8.75, PHP 7.4, MySQL 8 (tests run against real MySQL — `phpunit.xml` sets `DB_CONNECTION=mysql`, `DB_DATABASE=bengkel_testing`), Blade + Bootstrap 5, no SPA/build step.

## Global Constraints

- PHP 7.4.33 — no PHP 8+ syntax anywhere.
- Every list endpoint uses `->simplePaginate()`, never `->paginate()`.
- **`AuditLogger::log()` must never throw.** Its entire body is wrapped in `try { ... } catch (\Throwable $e) { Log::error(...); }`. This is what makes it safe to call from inside an existing `DB::transaction()` closure without risk of an audit-write bug rolling back the real business change.
- **`branch_id` is always passed explicitly by the caller** — never inferred by reflecting on the auditable model, since `StockTransfer` has `from_branch_id`/`to_branch_id` instead of a plain `branch_id`.
- **`audit_log.view` is a GLOBAL permission** (`is_branch_scoped => false` in the seeder) — `AuditLogController::index()` uses a bare `$this->authorize('audit_log.view')`, and its Cabang filter lists every branch in the system (`Branch::orderBy('name')->get()`), not `branchesWithPermission(...)`. Do not copy the Receivables Report's branch-scoped pattern here; it does not apply.
- Every integration point (Tasks 2-4) is a single additive line inserted right before the existing `return`/end of an existing `DB::transaction()` closure — never restructure the surrounding method, never change its existing return value, error paths, or locking order.
- New files use the existing project conventions exactly: services instantiated (`(new AuditLogger())->log(...)`, matching `(new DocumentNumberGenerator())->next(...)`), migrations use `Schema::create`/raw `DB::statement` for anything beyond Blueprint's fluent API, tests extend `Tests\TestCase` with `use RefreshDatabase`.

```php
<?php

namespace App\Services;

use App\Models\AuditLog;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Facades\Log;
use Throwable;

class AuditLogger
{
    public function log(string $event, ?int $branchId, ?Model $auditable, array $oldValues = [], array $newValues = []): void
    {
        try {
            AuditLog::create([
                'branch_id' => $branchId,
                'user_id' => auth()->id(),
                'event' => $event,
                'auditable_type' => $auditable ? $auditable->getMorphClass() : null,
                'auditable_id' => $auditable ? $auditable->getKey() : null,
                'old_values' => $oldValues ?: null,
                'new_values' => $newValues ?: null,
                'ip_address' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ]);
        } catch (Throwable $e) {
            Log::error('Audit log write failed', [
                'event' => $event,
                'exception' => $e->getMessage(),
            ]);
        }
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Models\AuditLog;
use App\Models\Branch;
use App\Support\AuditEvent;

class AuditLogController extends Controller
{
    public function index()
    {
        $this->authorize('audit_log.view');

        $branches = Branch::orderBy('name')->get();

        $branchIds = collect(request('branch_ids', []))
            ->map(fn ($id) => (int) $id)
            ->intersect($branches->pluck('id'))
            ->values()->all();

        $userSearch = is_string(request('user')) ? trim(request('user')) : null;

        $event = request('event');
        $event = array_key_exists($event, AuditEvent::LABELS) ? $event : null;

        $dateFrom = $this->parseDate(request('date_from'));
        $dateTo = $this->parseDate(request('date_to'));

        $logs = AuditLog::with(['branch', 'user'])
            ->when($branchIds, fn ($q) => $q->whereIn('branch_id', $branchIds))
            ->when($userSearch, function ($q, $term) {
                $escaped = addcslashes($term, '%_\\');
                $q->whereHas('user', function ($inner) use ($escaped) {
                    $inner->where('name', 'like', "%{$escaped}%");
                });
            })
            ->when($event, fn ($q) => $q->where('event', $event))
            ->when($dateFrom, fn ($q) => $q->whereDate('created_at', '>=', $dateFrom))
            ->when($dateTo, fn ($q) => $q->whereDate('created_at', '<=', $dateTo))
            ->orderByDesc('created_at')
            ->orderByDesc('id')
            ->simplePaginate(20)
            ->withQueryString();

        return view('audit-logs.index', [
            'logs' => $logs,
            'branches' => $branches,
            'selectedBranchIds' => $branchIds,
            'userSearch' => $userSearch,
            'event' => $event,
            'dateFrom' => $dateFrom,
            'dateTo' => $dateTo,
        ]);
    }

    protected function parseDate(?string $value): ?string
    {
        if (! is_string($value) || ! preg_match('/^\d{4}-\d{2}-\d{2}$/', $value)) {
            return null;
        }

        return $value;
    }
}
```
